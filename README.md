# Meowdoku Duel

Судоку для двух друзей в браузере. Статический сайт для GitHub Pages, Safari на iPhone и Chrome на Android. Установка и регистрация не нужны.

Создатель нажимает «Создать комнату», отправляет другу ссылку и держит вкладку открытой. Второй игрок открывает ссылку и вводит имя. Создатель выбирает сложность и запускает общий раунд. Счёт сохраняется между раундами; после обновления той же вкладки комната восстанавливается из локального хранилища.

Для публикации в GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root) → Save. Файлы приложения должны лежать в корне репозитория.

Ходы передаются через MQTT поверх TLS WebSocket с шифрованием AES-GCM. Два публичных реле — EMQX и HiveMQ — используются для устойчивости к недоступности одного из них. Доступность реле зависит от сети и сторонних сервисов; собственного SLA у приложения нет. Домен ChatGPT не используется. Ссылка содержит случайный ключ комнаты: пересылайте её только сопернику.

Состояние и проверка ходов находятся в браузере создателя комнаты. Ответы и поле другого игрока не передаются сопернику. Это игра для друзей, без защиты от модификации клиентского кода создателем. При закрытии или приостановке вкладки хозяина связь прерывается; после возвращения вкладки и восстановления интернета игра может продолжиться. Не блокируйте экран во время дуэли. Сложность задаёт число открытых клеток, а не рейтинг стратегий решения.

Все пути относительные: сайт поддерживает адрес вида `https://USERNAME.github.io/meowdoku/`. Для локальной проверки нужен HTTP-сервер, например `python3 -m http.server 8000` из каталога приложения. HTTPS необходим для Web Crypto API в опубликованной версии.

Тесты: `node --test game.test.mjs transport.test.mjs` (Node.js 24+). Проверены правила, уникальность решений для трёх сложностей, ограничение двух участников, приватность полей, отсчёт, победа и счёт, шифрование и устранение дубликатов на симуляторе реле. Соединение через публичные реле на физических iPhone и Android требует проверки после публикации.
