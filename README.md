# Meowdoku 1×1

Браузерная дуэль с расстановкой котиков. https://calm4.github.io/meowdoku1x1/

Код комнаты — 5 английских букв/цифр без неоднозначных I/O/0/1. Создатель выбирает сложность, отправляет код или ссылку другу и запускает общий отсчёт. Игровой экран открывается отдельно от лобби. Сверху — ники и общий счёт комнаты по выигранным партиям; история партий доступна в комнате.

## Правила и источники

Оригинальная игра — Meowdoku! / Meowdoku: Brain Puzzle Games от Oakever Games. Это независимая браузерная реализация с собственными полями и рисунками, дополненная режимом дуэли.

- [Описание разработчика в App Store](https://apps.apple.com/us/app/meowdoku/id6761760135): один котик в каждой цветной области, без общих строк/столбцов и без соседства, включая диагональное; двойной тап ставит котика; три сердца.
- [Описание в Google Play](https://play.google.com/store/apps/details?id=com.oakever.meowdoku): те же ограничения и механика попыток.
- [Обзор с игровым процессом Android Central](https://www.androidcentral.com/apps-software/meowdoku-is-sudoku-but-with-cats-and-it-is-highly-addictive-but-it-has-one-big-problem): три ошибки завершают попытку; некоторые поля имеют заранее открытого котика; есть подсказки и ежедневные задачи.
- [Ответы разработчика в App Store](https://apps.apple.com/sa/app/meowdoku/id6761760135): отмена и черновик менялись и тестировались между версиями. Свойства сторонних браузерных клонов не считаются официальными правилами.

Правило соседства запрещает только восемь ближайших клеток, а не всю диагональ. Крестики — пометки, а не котики; они не расходуют попытки. В нашей версии один тап переключает крестик, два быстрых тапа ставят котика; проведение по полю ставит/убирает пометки. Принятые корректные котики остаются на месте. Необязательные автопометки исключают общую строку, столбец, цвет и соседние клетки. Подсказок в дуэли нет.

Банк содержит 180 собственных полей с единственным решением и связными областями: по 60 каждого типа. Сложность оценивается по видимой расстановке, без использования ключа ответов: лёгкая решается одиночными кандидатами, средняя требует исключений на пересечениях строк/столбцов и областей, а сложная не решается одними одиночками и пересечениями — после них остаются минимум четыре котика, требующие более сильных рассуждений или проверки вариантов. Размеры по-прежнему 5×5, 6×6 и 7×7, но сами по себе размер и цвет не определяют категорию. Выбор поля не повторяет исходные задачи в комнате, пока не исчерпан пул сложности. Отражения, повороты и перестановки цветов создают визуальные варианты. У обоих игроков одна и та же задача и одинаковые исходные условия.

## Правила дуэли

Ошибка добавляет 10 секунд к итоговому времени и отнимает сердце. Третья ошибка немедленно отдаёт партию сопернику. Победитель по скорости определяется по времени решения плюс штрафам. Если первый завершивший поле имеет штраф, второй может закончить позже по реальному времени и выиграть по итоговому. Первый завершивший видит экран ожидания. По скорости результат объявляется только после того, как оба завершат поле: даже если время второго уже больше лучшего результата, он может закончить свою головоломку. Исключение — третья ошибка, которая по-прежнему сразу завершает партию поражением ошибившегося. Очки и история сохраняются между партиями; перед следующим раундом можно сменить сложность.

## Связь и сохранение

Сайт работает на GitHub Pages без доменов ChatGPT и без установки приложений. Данные передаются через MQTT по TLS WebSocket с AES-GCM. Два публичных реле — EMQX и HiveMQ — используются для устойчивости к отказу одного сервиса. Доступность зависит от сторонних реле и сети; SLA не предоставляется.

Короткий код предназначен для удобного входа друзей, а не для передачи конфиденциальных данных. Не публикуйте код комнаты. Создание проверяет наличие активной комнаты с таким кодом, но абсолютной гарантии отсутствия коллизий у распределённого реле нет.

Создатель хранит состояние в своём браузере и проверяет ходы. Поле соперника и ответ в сообщениях гостю не передаются. Это игра для друзей, без защиты от модифицированного кода создателя. Вкладки нужно держать открытыми, экраны — активными; iOS и Android могут приостанавливать фоновые страницы. После возвращения связь восстанавливается, при обновлении той же вкладки доступ и состояние читаются из локального хранилища. Ходы гостя упорядочены, повторная доставка через два реле не удваивает ошибки или очки. Время опирается на часы создателя с поправкой часов гостя; сеть может добавлять задержку к фиксации хода.

Белые SVG-крестики с тёмной обводкой появляются с анимацией рисования; сетевые обновления не пересоздают их. Распознавание двух тапов привязано к одной клетке и типу указателя: нативный счётчик dblclick не ставит котиков. Звук можно включить кнопкой ♫. Анимации уважают настройку уменьшения движения. Виброотклик используется только там, где браузер поддерживает Vibration API; Safari на iPhone его не поддерживает.

## Проверка

`node --test game.test.mjs input.test.mjs transport.test.mjs` — уникальность и связность полей, ограничения размещения, права создателя, отсчёт, приватность поля, три ошибки, штрафные секунды, порядок победы, перенос счёта, 5-символьный код, шифрование и устранение повторной доставки.

Дополнительно проверен полный сценарий в Chromium с экранами 390×844 и 412×915: два изолированных браузера, вход по коду, переход в игру, пометки и двойные тапы, штраф, финиш обоих игроков, новая партия другой сложности, поражение после третьей ошибки и счёт 1:1. Отдельно проверены быстрые одиночные тапы по разным клеткам (включая постороннее событие dblclick), отсутствие ложных котиков/штрафов, белые SVG-крестики и сохранение их DOM при синхронизации, а также завершение обоих полей без раннего отключения соперника. Банк можно пересобрать командой `node tools/build-puzzle-bank.mjs`. Тест использует симулятор MQTT-реле; физические устройства и доступность публичных реле из сетей игроков не проверялись.

Все пути относительные. Для локального запуска достаточно `python3 -m http.server 8000` из этого каталога. Web Crypto требует HTTPS либо localhost. Публикация запускается workflow `.github/workflows/pages.yml`, а также поддерживается стандартная публикация GitHub Pages из main / root.
